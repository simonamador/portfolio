# Carlos Simón Amador Izaguirre Portfolio

Personal website for `simonamador.com`, hosted on GitHub Pages from the `simonamador.github.io` repository.

## Structure

- `index.html` — English canonical homepage.
- `es/index.html` — Spanish/LATAM landing page with hreflang support.
- `styles.css` — shared visual system.
- `img/` — optimized, descriptive image assets.
- `cv/` — CV/resume files and BibTeX placeholder. Replace placeholder files with final artifacts before public launch.
- `robots.txt` and `sitemap.xml` — search-engine discovery files.
- `CNAME` — GitHub Pages custom-domain configuration for `simonamador.com`.

## Deployment

Push to the default branch of `simonamador/simonamador.github.io`. GitHub Pages serves the site at:

- `https://simonamador.com/`
- `https://simonamador.com/es/`

After deployment, validate:

1. `https://simonamador.com/robots.txt`
2. `https://simonamador.com/sitemap.xml`
3. Rich results at `https://search.google.com/test/rich-results`
4. Schema at `https://validator.schema.org/`
5. Lighthouse mobile performance and accessibility
